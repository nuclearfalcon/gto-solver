================================================================================
KEY IMPLEMENTATION DECISIONS
================================================================================

1. Python for-loops instead of jax.lax.scan
   - Required due to varying sparsity (different nse per level)
   - JAX scan requires uniform shapes
   - Trade-off: Memory savings >> performance loss

2. Removed dense stacked matrices in sparse mode
   - Initially kept for backward compatibility
   - Caused 8.2 GB memory usage
   - Removed after sparse batch code implemented
   - Result: 185x compression achieved

3. JIT compilation strategy
   - JIT single-config function, not entire batch
   - Prevents massive unrolled computation graphs
   - Enables reasonable compilation times
